# Personal Website

A simple resume and project page for Amir Elias, an NJIT computer science student. It uses HTML and CSS and includes education, tutoring experience, project links, and contact links.

## View locally

Download or clone the repository, then open `index.html` in a browser. Keep `style.css`, `amir.jpg`, and `backgroundImage.jpg` beside it. No package installation, build step, or server is needed.

- Rochester Institute of Technology: attended and studied Computer Information Technology.

## Files and publishing

- `index.html`: resume content and project links.
- `style.css`: page styling.
- `amir.jpg` and `backgroundImage.jpg`: page images.

This is a static page with no backend or contact form. The repository's GitHub Pages workflow publishes changes pushed to `main`; changes saved on another branch do not update the live website until they are merged and published.
